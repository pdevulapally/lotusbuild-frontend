## Direction contract

THESIS: This is a working tool a builder watches and steers for extended sessions, not a chat-app wrapper. It refuses the category default every AI-agent product ships: a floating rounded chat card, avatar-bubble messages, and a soft colored backdrop around the "real" content.

OWN-WORLD: LotusBuild's own existing, locked system — no new colors, no new type. Warm paper page (`--page`), greige panel tint (`--surface`) reserved for the sidebar/secondary layer, near-white content plane (`#fffdfb`) for the working canvas, ink/muted text, hairline dividers (`--line`), single rust accent (`--accent`) reserved for focus rings and selection only, never decoration. One workhorse sans (Public Sans) carries the whole surface — Operate mode doesn't need the display serif inside a dense tool. Edge-to-edge, no card, no shadow-as-decoration, thin 1px structural rules doing the separating.

STORY: The builder opens a project and immediately reads where the build stands — status, live desktop, event history — without hunting. The agent's output reads as flowing document text with a quiet byline, not chat bubbles. Follow-ups and stop stay reachable without leaving flow. Mobile gets the same information, tab-switched, never a cut-down experience.

FIRST VIEWPORT: Edge-to-edge, three regions, no outer inset. Quiet left rail (project + session index, `--surface` tint, hairline right border) · conversation as flowing document (byline labels, quote-rule for the user's own words, no avatars, no bubbles) · live desktop + activity stacked right, divided by a real resizable handle. Status lives in the header as one small solid chip, not a badge-shaped afterthought.

FORM: Established-world extension — Devin's and Cursor's actual signed-in app structure (session rail, dense conversation, tool/desktop panel) translated into LotusBuild's own locked palette and type. concept-seed (surface scope, seed key `3645b38b`) was run and declined: all three dealt challengers (teletext magazine, labanotation dance score, ASCII glyph render) are foreign visual/material systems incompatible with a locked neutral palette and a professional dev-tool register; logged, not used.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
